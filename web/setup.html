配置引导

服务已经启动，但还没有找到有效的 config.json。完成账号凭证配置后，额度面板和使用分析就可以正常工作。

⚠
如果你使用 Docker，请确认宿主机上的配置文件已经创建。宿主机文件不存在时，Docker 可能会把 config.json 自动创建成目录。
1
打开配置页面

先配置网络代理（如不需要代理可选择直连），再粘贴浏览器中成功的 Fetch / cURL 请求。

2
识别并保存账号凭证

系统会从请求中识别 Authorization、Cookie 和账号信息，测试成功后保存到配置文件。

3
返回面板

保存完成后重新打开首页，服务会开始显示额度、重置时间和使用统计。

打开配置页面
Docker 未创建配置文件？先在宿主机创建模板 
cp config.example.json config.json
docker compose up -d

Windows PowerShell 可使用：Copy-Item config.example.json config.json。创建文件后重新创建容器，配置页面保存的内容会保留在宿主机。
